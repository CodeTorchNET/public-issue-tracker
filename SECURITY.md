# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately in one of these ways:
- Use GitHub's "Report a vulnerability" button in this repository's Security tab
- Email security@codetorch.net

Please include a description of the issue, steps to reproduce it, and any proof-of-concept files.

We'll acknowledge your report as soon as we can, keep you updated while we work on a fix, and credit you once it's resolved if you'd like.

## Scope

This policy covers codetorch.net, CodeTorch for Education instances, and all repositories under the CodeTorchNET organization.
